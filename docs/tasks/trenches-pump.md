# Trenches Market на Pump.fun — план

Основание: [ADR 0006](../decisions/0006-trenches-on-pump.md). Статус по шагам ведётся здесь.

| # | Шаг | Кто | Готово, когда | Статус |
|---|---|---|---|---|
| 1 | Декодер bonding curve Pump.fun в DC Chain | агент | разбор аккаунта по IDL, цена в USDC, капитализация, `complete`; офлайн-тесты | готово |
| 2 | Конфиг рынков предметов + чтение через RPC | агент | 7 предметов, mint `null` до запуска; один `getMultipleAccounts` на все кривые; loopback-тест | готово (подключено к странице предмета) |
| 3 | Чтение PumpSwap после graduation | агент | цена из пула с `effective_quote_reserves`; тест с отрицательным `virtual_quote_reserves` | готово (на mainnet не проверено: нет выпущенного предмета) |
| 4 | Убрать симуляцию item shares из UI | агент + владелец | каталог, Home S2 и `/market/[id]` на одном источнике: превью до запуска, затем on-chain; `My positions` из кошелька | готово |
| 5 | Запуск USDC (без mayhem mode) | владелец | mint записан в `usdcMint` в `src/resources/launch.ts`; снимок рынка собирается для нового mint | ждёт |
| 6 | Запуск 7 предметов с quote = USDC | владелец | 7 mint'ов записаны в `src/resources/launch.ts`; сайт показывает живые цены | ждёт шага 5 |
| 7 | Снапшот трейдинга предметов для NFT-аирдропа | агент | скрипт: кошелёк → объём/число сделок по 7 предметам на слоте; повторный запуск даёт тот же файл | ждёт шага 6 |

Агент не выполняет запуски монет и любые транзакции: это делает владелец своим кошельком.

## Проверки

- `npm run test:contracts` — декодер и чтение рынков (офлайн, loopback RPC).
- `npm run typecheck`, `npm run check:dc-chain`.
